# Hoodstampy 🦅

> Stamp your token into Robinhood Chain.

Launch a native Pons Family coin while permanently inscribing its media on Robinhood Chain. Real coins, on-chain media, immutable once stamped.

## Features
- **Permanent Inscriptions**: Inscribe token images, animations, audio directly into the Robinhood Chain.
- **Pons Family Integration**: Seamless launchpad layer on Pons Family.
- **Arcade & Docs**: Built-in interactive terminal, explorer, and full documentation.
- **Live Board**: Track inscriptions and trending tokens.

## Token
- Symbol: `$HSTAMPY`
- Chain: Robinhood Chain
